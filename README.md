# 🍪 Cookie Clicker Bot
# DAY - 48/100 Project - python x Cookie Clicker Bot

An autonomous Cookie Clicker bot built using Python and Selenium.

The bot automatically:
- Clicks cookies continuously
- Purchases upgrades automatically
- Buys the best available products
- Optimizes cookie production over time

---

# 🚀 Features

✅ Automated cookie clicking  
✅ Upgrade purchasing system  
✅ Product purchasing automation  
✅ Autonomous gameplay loop  
✅ Selenium browser automation  
✅ Dynamic DOM interaction  

---

# 🛠️ Built With

- Python 3
- Selenium
- ChromeDriver

# ▶️ Installation

## Clone Repository

```bash
git clone https://github.com/guptaji0358/cookie-clicker-bot.git
```

## Open Project Folder

```bash
cd cookie-clicker-bot
```

## Install Dependencies

```bash
pip install selenium
```

---

# ▶️ Run The Bot

```bash
python 48_COOKIE_CLICKER_BOT.py
```

---

# 🤖 How It Works

The bot:
1. Opens Cookie Clicker in Chrome
2. Continuously clicks the cookie
3. Detects available upgrades
4. Purchases affordable products automatically
5. Increases cookie production over time
